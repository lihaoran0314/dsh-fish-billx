# dsh-fish-billx

B 站语料学习插件 for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)。

抓 B 站一个话题下的整篇材料 —— 标题、简介、标签、高赞评论（含楼中楼）、弹幕 ——
把**整篇当一个文档**读给模型，提炼成 7 类可迁移的知识，然后按当前话题把它们喂回系统提示词。

一句话：让跑在 DSH 里的助手学会「评论区怎么说人话」，而不是背台词。

```
       抓            学                    用
B 站 ──→ raw.json ──→ knowledge.json ──→ 每轮系统提示词
         整篇材料      7 类知识             按话题挑几条
```

---

## 一、装

```bash
# 在 DSH profile 里装（会写进当前 profile 的 cordis.patch.yml）
dsh plugin add dsh-fish-billx
```

或者手动：把这个仓库链进 profile 的 `package.json`，再在 `dsh.profile.bundles` 里加一项 `dsh-fish-billx`。

配置全部可选，写在 profile 的 `cordis.patch.yml`：

```yaml
- id: dsh-fish-billx
  name: dsh-fish-billx
  config:
    videosPerRun: 3        # 一轮抓几个视频
    commentsPerVideo: 40   # 每个视频留多少条高赞评论
    danmakuPerVideo: 60    # 每个视频留多少条弹幕，0 = 不要
    promptEnabled: true    # 要不要注入提示词
    promptBudget: 900      # 注入内容的字数硬上限
    keywords: []           # 想固定学某类内容才填；留空 = 按话头走
    cookie: ""             # B 站 SESSDATA，不填按游客抓
```

> 语料落在 `$DSH_HOME/dsh-fish-billx/corpus/`（默认 `~/.dsh/dsh-fish-billx/corpus/`），
> 不在工作区里，换项目不会丢。想换位置就设 `config.dataDir`。

## 二、用

插件注册 9 个工具，模型会自动调；你也可以直接说人话。

| 工具 | 干什么 |
| --- | --- |
| `fish_learn` | 抓 + 学（最常用）。不给关键词就从最近对话里自己找话题 |
| `fish_crawl` | 只抓不学，攒一批语料再一起学 |
| `fish_state` | 现在学到多少、各类条数、最近几轮、正在跑的任务 |
| `fish_knowledge` | 看具体学到了什么，可以只要某一类 |
| `fish_coin` | 造梗机：拿学到的梗 + 造梗手法现造新词（只给候选，不入库） |
| `fish_remember` | 手工收一条（造好的梗、改错的词） |
| `fish_forget` | 删掉学歪的那一条 |
| `fish_preview` | 预演：这句话会注入哪几条、哪个开关被触发 |
| `fish_log` | 读人能看的学习日志，或清空某一部分 |

典型用法：

```text
「学点 B 站原神抽卡的语料」        → fish_learn keyword="原神 抽卡"
「我们现在在聊螺蛳粉，去学一下」    → fish_learn texts=[...]  自己提话题
「学会的东西给我看看」              → fish_knowledge
「期末周能造几个词吗」              → fish_coin keyword="期末周"
「这句话会往提示词里塞什么」        → fish_preview text="..."
```

## 三、学什么（7 类，刻意分开）

| 类别 | 学的是什么 | 什么时候用它 |
| --- | --- | --- |
| **梗** `memes` | 黑话、缩写、固定句式、评论区玩法 | 对方话里出现过的优先，最多 4 条 |
| **造梗手法** `coinage` | 这群人**怎么造**新说法：谐音、旧梗拼贴、缩写、反转 | 玩梗时 2 条，平时 1 条 |
| **涌现现象** `emergence` | 没人组织却自己长出的接龙、默契、集体玩法 | 2 条，要求别生硬引用 |
| **道德边界** `ethics` | 哪句话越界了：地狱笑话、歧视、羞辱当事人 | **只在碰到雷区时**带 |
| **常用词** `commonWords` | 这圈人挂在嘴边的词、语气词、口头禅 | 3 条，多了就成学舌 |
| **游戏词汇** `gameWords` | 游戏名与圈内术语，给圈内意思 | **只在聊游戏时**带 |
| **爱的能力** `love` | 真心关心、护短、哄人的说法 | 2 条，用她自己的话说 |

混在一起学，最后只剩一堆没有上下文的词。所以知识按词条累积：同一个词再学一次
`weight + 1`，例子最多留 4 条，来源留最近 8 个 BV 号。

### 整篇学习，不是切碎了抓梗

一个视频的材料按 ~3200 字一批打包，最多 3 批，整体交给模型，并且要求它先给
一句 `summary` 说清「这期评论区在玩什么」。这句 summary 会进学习日志 ——
宏观回看时最有用。

### 内容安全闸

ASMR / 擦边 / 成人向的材料**整条不抓、不学**（标题、简介、标签命中就跳过；
评论区有 3 条以上聊这些也放弃）。脏话和歧视词进不了「梗 / 常用词 / 游戏词汇」
三张表。`ethics` 这一类**强制不存原文例子**，只写「为什么伤人 / 怎么识别 / 该怎么办」。

## 四、抓取踩过的四个坑（都已经处理）

1. **评论接口换了。** 老的 `/x/v2/reply` 现在只回 3 条热门；要 20 条得用
   `/x/v2/reply/wbi/main`，还要带 `w_rid` 签名（`md5(排序后的 query + mixinKey)`，
   mixinKey 由 `nav` 返回的 img/sub key 按固定表重排）。key 缓存 30 分钟，
   新接口拿不到就自动退回老接口。
2. **弹幕接口会自己 gzip/deflate，而且是裸 deflate。** `createInflate` 直接报错、
   整块丢成 0 条。现在 raw → zlib → 原文三种都试。
3. **`ps` 有上限。** 填 30 会 `-400 ps out of bounds`，评论全空。
4. **并发会被风控。** 详情/标签/评论/弹幕同时打容易 `-352`，现在串行 + 小间隔。

## 五、关于模型：预算，不是模型挑食

提炼走 DSH 自己的 `ctx.llm`，不额外要 Key。**早期版本的结论「只有一个模型能跑」是错的**，
原因是请求太紧，不是模型不行。三个连锁问题，都已修复。

### 1. token 预算给少了（真凶）

推理型模型会先把预算烧在思考上，**烧完就返回空内容**（`finish_reason: length`，`content` 为空）。
把预算固定成 3000 时，同一份 3200 字材料、同一个提示词：

| 模型 | 3000 | 8000 | 12000 |
| --- | --- | --- | --- |
| `deepseek-v4.1-flash` | ❌ 空 | ❌ 空 | ✅ 推理 6534 后正常输出 |
| `deepseek-v4-pro` | ❌ 空 | ❌ 空 | ✅ 推理 8692 后正常输出 |
| `glm-5.3-flash` | ✅ 推理 2518 | ✅ | ✅ |
| `kimi-k2.7-code` | ✅ 但见下面第 2 条 | ✅ | ✅ |

所以 `EXTRACT_MAX_TOKENS` 定在 **12000**。另外试过 `reasoning_effort=low/minimal`、
`enable_thinking=false` —— 在这个网关上全被忽略，推理量反而升到 8700 左右。
**只有加预算有效**，所以加预算。

### 2. `[batch 1/2]` 这个标签会骗模型等下文

kimi 看到分批标签就只回一句「请继续发送 batch 2/2」，抽到 0 条，**但这依然是合法 JSON**。
现在每次调用都明确告诉模型「这就是全部输入，不要再等，立刻输出 JSON」。改完 kimi 从 0 条变 37 条。

### 3. 合法但空的 JSON 不能当成「这里没内容」

`{"memes":[], ...}` 解析得过，看起来像成功。现在判成功看**实际条目数**，为 0 就抬到
24000 预算重试一次；还不行才退回本地统计，并在 `error` 里说清原因。

修完之后，同一份材料实测：

| 模型 | 结果 |
| --- | --- |
| `deepseek-v4.1-flash` | ✅ 38 条（7 类全中） |
| `glm-5.3-flash` | ✅ 34 条 |
| `kimi-k2.7-code` | ✅ 37 条 |

代价是慢：一次提炼 90–125 秒（推理本身就要几十秒）。抓一个视频换这个质量，值。

`fish_state` 和日志里始终能看到 `method` 是 `llm` 还是 `heuristic`，
以及失败时到底卡在哪一步。

仓库里带探测脚本，换模型/换网关时先跑一遍：

```bash
node scripts/probe-model.mjs      # 这个网关通不通
node scripts/probe-budget.mjs     # 小任务下预算是否正常
node scripts/probe-learn.mjs      # 拿真实语料跑长文档提炼
node scripts/probe-matrix.mjs     # 模型 × 预算矩阵，找最小可用预算
node scripts/diagnose-model.mjs   # 逐项隔离：输入长度 / 输出复杂度 / 预算
node scripts/probe-verify.mjs     # 端到端跑 learnOne，看真实落库条数
```

没有模型也能用：`fish_learn({useLlm:false})` 走本地统计（重复出现的说法 = 梗，
关心的话 = 爱，出现游戏名 = 游戏词汇），质量差一档但不会空手而归。
`fish_coin` 没有模型时直接拒绝 —— 不编。

## 六、注入策略（为什么不会撑爆提示词）

- **梗**：对方话里出现过这个词的优先，再按权重补，最多 4 条；**完全没命中时只补 2 条**
  （否则每天聊天都被塞游戏专用梗，语气会被带跑偏）
- **造梗手法**：玩梗/问新词时 2 条，平时 1 条
- **常用词**：3 条，多了就成学舌
- **游戏词汇**：只有命中游戏词才带
- **道德边界**：只有碰到雷区才带（平时带等于提醒它去想那些东西）
- **涌现 / 爱**：各 2 条
- 总长 `promptBudget` 硬上限，超了从最后一组开始砍

注入是「best-effort」：读语料失败绝不让这一轮对话失败。

## 七、开发

```bash
npm test        # 33 条，全部纯本地，不联网
npm run verify  # 插件名一致性 + 9 个工具能否被真实注册表接受 + 有没有密钥混进仓库
```

测试覆盖：7 类提炼与合并、脏数据过滤、整篇分块、提示词开关与预算、
话题提取、并发保护、工具定义的注册表形状，以及 `apply()` 真的注册了 9 个工具并
把语料段落追加进 `system-prompt/assemble`。

`npm run verify` 干的是自测做不到的事：它加载 DSH 真身的 `defineTool`，确认
`package.json` 的包名、导出的 `name`、运行时的 `state.id` 三者一致且 9 个定义全部
被接受。**改名字或改工具定义后先跑这个** —— 只跑自测的话，名字改一半、或者在真实
注册表那里被拒，都发现不了。

数据文件：

```
~/.dsh/dsh-fish-billx/corpus/
├─ raw.json        # 抓到的视频（整篇材料），最多 300 条
├─ knowledge.json  # 7 类知识（v2）
├─ state.json      # 最近 30 次运行摘要
└─ learn-log.md    # 人能直接读的学习日志
```

## 八、合规

- 只抓 B 站**公开接口的公开内容**，低频（每轮 2~3 个视频、请求间隔 200~400ms）。
  **别调大并发**，风控是你自己的账号在扛。
- 只学「说法」，不存用户隐私；评论只留正文和点赞数。
- 道德边界只学「识别 + 反应」，不复述、不传播歧视内容。
- 学到的梗只在本地提示词里用，**不会**自动去评论、发视频。
